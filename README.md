# file-organizer

Small Windows 11 app that tidies loose files in Downloads, Desktop and Documents into
`<Type>\<YYYY-MM>\` folders, with a preview, a journal and undo. See `README.txt` for users.

- `core/` – library with all logic (no GUI), tested in `core/tests/`.
- `src/` – egui window.
- Download: the `latest` release (`file-organizer.zip`).
